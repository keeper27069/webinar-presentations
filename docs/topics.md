# Все темы вебинаров (78)

> Источник для кода — `src/lessons/topics.ts` (там же переводы названий на uz/en). Этот файл — описания уроков из учебного плана для методиста и для Claude.

Формат: прямой эфир на YouTube, ученики участвуют через чат. Возраст 10–17.
- **Общие (g)** — самостоятельные уроки о том, как устроены технологии, работа с клиентом, AI и карьера. Без кода или с минимумом кода. Шаблон: открытие через эксперименты (см. lesson-design → «Общая тема»). 14–15 сцен.
- **Технические (t)** — практика, дополняющая программу платформы: живой код, демо, «найди баг». 10–12 сцен.

Каждую неделю: 1 техническая + 1 общая тема. Ученики к моменту темы прошли предыдущие темы своего модуля и все предыдущие модули (порядок модулей: HTML → CSS → Bootstrap → Tilda Git → JS → React). Опирайся на это: в CSS-уроке можно использовать HTML, в React-уроке — JS, но не наоборот.

`id` = `<module>-<g|t><NN>`; URL урока: `/<lang>/<module>/<slug>`.

| Модуль (id) | Длительность | Общих | Технических | Цвет-акцент (рекомендация) |
|---|---|---|---|---|
| HTML (`html`) | 1 мес | 5 | 4 | оранжевый |
| CSS (`css`) | 2–2,5 мес | 10 | 10 | синий |
| Bootstrap (`bootstrap`) | 1 мес | 5 | 5 | фиолетовый |
| Tilda Git (`tilda-git`) | 1,5–2 мес | 7 | 7 | бирюзовый |
| JS (`js`) | 1,5 мес | 6 | 7 | жёлтый |
| React (`react`) | 1,5 мес | 6 | 6 | голубой (cyan) |
